# OctoCert — Πιστοποιητικά & επανέλεγχοι

Πρώτη απλή εφαρμογή στα ελληνικά, χωρίς εγκατάσταση ή διακομιστή.

## Πώς βλέπω την εφαρμογή

1. Στον χώρο εργασίας ανοίξτε τον φάκελο `octocert-date`.
2. Ανοίξτε το `index.html` με την προεπισκόπηση HTML του επεξεργαστή, εφόσον διατίθεται.
3. Εναλλακτικά, κατεβάστε στον υπολογιστή σας τα `index.html`, `style.css`, `app.js` στον ίδιο φάκελο. Κάντε διπλό κλικ στο `index.html` για να ανοίξει στον browser (Chrome, Edge ή Firefox).
4. Θα δείτε 8 εικονικά πιστοποιητικά. Οι αρχικές ημερομηνίες δημιουργούνται σε σχέση με την ημέρα της πρώτης εκκίνησης.
5. Πατήστε **Νέο πιστοποιητικό**, συμπληρώστε όλα τα πεδία και **Αποθήκευση**.
6. Αναζητήστε πελάτη, εγκατάσταση ή αριθμό. Η αναζήτηση αγνοεί πεζά/κεφαλαία και τόνους. Συνδυάζεται με το φίλτρο κατάστασης.
7. Πατήστε **Επεξεργασία** στη γραμμή για να αλλάξετε στοιχεία.

Κόκκινο: επανέλεγχος πριν από σήμερα. Πορτοκαλί: σήμερα έως και 30 ημέρες μετά. Πράσινο: μετά τις 30 ημέρες. Η σημερινή ημερομηνία υπολογίζεται στη ζώνη Europe/Athens.

## Πού αποθηκεύονται τα δεδομένα

Οι καταχωρίσεις αποθηκεύονται αυτόματα στο localStorage του συγκεκριμένου browser, για τη συγκεκριμένη διεύθυνση της εφαρμογής. Παραμένουν μετά την ανανέωση, εφόσον ο browser επιτρέπει τοπική αποθήκευση. Σε ιδιωτική περιήγηση μπορεί να χαθούν με το κλείσιμο. Αλλαγή συσκευής, browser, διεύθυνσης ή διαγραφή δεδομένων περιήγησης δεν μεταφέρει τις καταχωρίσεις. Η συμπεριφορά σε `file://` εξαρτάται από τον browser.

Το **Εξαγωγή δεδομένων** κατεβάζει αρχείο JSON ως αντίγραφο. Η πρώτη έκδοση δεν έχει εισαγωγή αρχείου, κοινή βάση δεδομένων ή αυτόματες ειδοποιήσεις.

## Πώς αποθηκεύω τον κώδικα στο GitHub — με GitHub Desktop

Το GitHub κρατά τον **κώδικα** της εφαρμογής, όχι τις καταχωρίσεις του browser.

1. Εγκαταστήστε το GitHub Desktop από https://desktop.github.com και συνδεθείτε στον λογαριασμό σας.
2. Επιλέξτε **File → Clone repository → URL** και βάλτε `https://github.com/gkounatidis-prog/octocert-date.git`.
3. Επιλέξτε έναν τοπικό φάκελο και πατήστε **Clone**.
4. Αν η εφαρμογή σας έχει δοθεί ως αρχεία από τον χώρο εργασίας, αντιγράψτε `index.html`, `style.css`, `app.js` και `README.md` μέσα στον φάκελο που μόλις δημιουργήθηκε. Κρατήστε τον κρυφό φάκελο `.git` ως έχει.
5. Επιστρέψτε στο GitHub Desktop. Στο **Changes** θα δείτε τα αρχεία που άλλαξαν.
6. Στο **Summary** γράψτε `Πρώτη έκδοση εφαρμογής OctoCert` και πατήστε **Commit to …**. Το commit είναι ένα τοπικό αποθηκευμένο στιγμιότυπο.
7. Πατήστε **Push origin** ή **Publish branch**, αν εμφανίζεται αυτό. Τότε ανεβαίνει το στιγμιότυπο στο GitHub.
8. Πατήστε **Repository → View on GitHub** και βεβαιωθείτε ότι φαίνονται τα νέα αρχεία στον επιλεγμένο κλάδο (branch).
9. Για κάθε επόμενη αλλαγή επαναλάβετε **Changes → Summary → Commit → Push origin**.

Αν δουλεύετε από τερματικό στον παρόντα χώρο εργασίας:

```sh
cd /workspace/octocert-date
git status
git add index.html style.css app.js README.md
git commit -m "Πρώτη έκδοση εφαρμογής OctoCert"
git push -u origin work
```

Ο τρέχων κλάδος είναι `work`. Αν χρησιμοποιείτε διαφορετικό κλάδο, βάλτε το όνομά του αντί για `work`. Το push ενδέχεται να απαιτεί σύνδεση στο GitHub. Δεν χρειάζεται να πληκτρολογήσετε κωδικούς μέσα στον κώδικα.

## Προαιρετική δημοσίευση με GitHub Pages

Αφού ανεβάσετε τα αρχεία: στο GitHub ανοίξτε **Settings → Pages → Build and deployment → Deploy from a branch**. Επιλέξτε τον κλάδο που έχει το `index.html` (π.χ. `work`) και φάκελο **/(root)**, έπειτα **Save**. Όταν ολοκληρωθεί η δημοσίευση, το GitHub θα εμφανίσει τον σύνδεσμο της εφαρμογής. Η διαθεσιμότητα εξαρτάται από τον τύπο λογαριασμού/αποθετηρίου. Το GitHub Pages μπορεί να κάνει την εφαρμογή δημόσια· χρησιμοποιήστε αρχικά μόνο τα δοκιμαστικά δεδομένα.

## Δομή

- `index.html`: οθόνη και φόρμα.
- `style.css`: εμφάνιση και προσαρμογή σε κινητό.
- `app.js`: αναζήτηση, ημερομηνίες, έλεγχοι και τοπική αποθήκευση.

Δεν απαιτείται `npm install` ή build για τη χρήση της εφαρμογής.
